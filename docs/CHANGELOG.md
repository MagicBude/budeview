# Changelog

## V0.1.0 — Design Baseline

- 建立正式产品文档结构。
- 冻结 Viewer First / Instant Open / Image First / Correct Pixels / Smooth Navigation / Local First / No Scope Creep 七项原则。
- 冻结 Windows-first。
- 冻结 .NET 10 LTS + Avalonia 12 + Native AOT 作为主 GUI 技术栈。
- 明确 UI 与 Decoder / Cache / Color / Huge Image / Codec Worker 解耦。
- 明确 P0 / P1 / P2 / Out of Scope。
- 明确键鼠、Viewer State、UI 布局、性能预算、测试和诊断原则。
- 记录前期竞品调研与技术 Benchmark 结论。
- 本版本不包含产品代码。
