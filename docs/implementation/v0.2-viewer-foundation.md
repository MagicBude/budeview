# V0.2 Viewer Foundation

## 目标

证明正式架构可以支撑一个真实可用的基础 Viewer，而不是继续做原型。

## 关键实现决定

### 当前图片优先

初次打开图片时：

- 当前图片 Decode
- 同目录扫描

并行启动，但 UI 首先等待当前图片，不等待目录扫描完成。

### Request ID + Cancellation

快速切图时取消上一个请求。

即使底层 Bitmap Decode 已无法中断，完成后的结果仍必须检查 Request ID，旧结果不能覆盖当前图片。

### Cache

V0.2 只实现基础有界 Decode Cache：

- 预算：256 MiB
- LRU
- 当前图片受保护
- 单张超预算大图允许临时独占，不因此无限保留其他图片

V0.3 再加入 Preload 和更完整的内存策略。

### 100% Pixel

Windows 高 DPI 下，100% 不能简单认为 `1 image pixel = 1 DIP`。

Viewer Surface 使用 `RenderScaling` 将图像像素换算到 DIP，目标是让 Actual Size 更接近 `1 image pixel = 1 device pixel`。

### UI

V0.2 暂时保留一条很小的开发工具栏和状态栏。

这不是最终 UI 设计。V0.3 以后继续向 `Image first, controls on demand` 收敛。

## 验收重点

V0.2 不评价“界面是否漂亮”，只看：

- 打开是否正确
- Viewer 几何是否正确
- 高频输入是否自然
- 快速切图是否安全
- 内存是否有边界
- 架构是否允许后续扩展
