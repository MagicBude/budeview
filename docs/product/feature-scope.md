# Feature Scope

## P0 — Viewer Core

- 双击 / 命令行 / Open 打开图片
- 拖入图片
- 同目录浏览上下文
- Natural Sort
- Previous / Next
- Fit Window / Width / Height / Fill
- 100% Pixel
- Zoom-to-cursor
- Pan
- Fullscreen / Frameless
- Rotate / Flip
- JPEG / PNG / GIF / WebP / BMP / TIFF / ICO / SVG
- AVIF / HEIC / JPEG XL
- GIF / APNG / Animated WebP
- Alpha / Checkerboard
- EXIF / Image Info
- ICC 基础色彩管理
- 删除到回收站、重命名、Copy、Explorer Reveal、Open With
- Keyboard / Mouse Mapping
- Windows File Association
- 异步解码、Cancellation、Preload、有界 Decode Cache

## P1 — Extended Viewer

- Portable Mode
- Filmstrip
- PSD / RAW / EXR Preview
- HDR / Ultra HDR
- ZIP / CBZ
- 多显示器色彩配置
- Huge Image / Tile Pipeline

## P2 — Specialized Viewing

- RAR / 7Z / CBR
- Compare 2-up / 4-up
- Sync Zoom / Pan
- Overlay / Difference
- Webtoon / Long Image
- Slideshow
- 动画逐帧控制

## Out of Scope

- 用户账号
- 云同步
- AI
- 图库数据库
- Album / Tag 管理
- 人脸识别
- DAM
- RAW 调色
- 图层编辑
- 绘画
- 批量转换中心
- 视频 / 音频播放器
- 社区与内容推荐
