# Product Principles

## 1. Viewer First
任何新功能首先回答：它是否直接帮助用户“看图片”？

## 2. Instant Open
启动、目录扫描、解码和窗口创建都围绕“尽快看到当前图片”排序。

## 3. Image First
默认最大化图片区域，控件按需出现。

## 4. Correct Pixels
正确处理 EXIF Orientation、Alpha、动画时序、ICC、SDR/HDR 和缩放采样。

## 5. Smooth Navigation
Previous / Next、Zoom、Pan、Fit / 100%、Fullscreen 必须稳定顺滑。

## 6. Local First
默认不联网、不上传、不登录、不遥测。

## 7. No Scope Creep
“也许有用”不是加入功能的理由，越界功能拒绝或拆成独立工具。
