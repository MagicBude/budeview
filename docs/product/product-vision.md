# Product Vision

## 一句话定位

BudeView 是一个**轻量、快速、本地优先、随开随用**的 Windows 桌面图片查看器。

## 要解决的问题

用户只是想看图时，不应该先面对：首页、相册、云空间、登录、推荐、AI、素材管理或数据库初始化。

理想流程是：`双击图片 → 图片出现 → 连续浏览 → 缩放 / 拖动 / 查看信息 → 关闭`。

## 成功标准

1. 图片足够快出现。
2. 连续切图顺滑。
3. 大图缩放和拖动稳定。
4. 色彩、透明度、方向和动画正确。
5. 常见格式无需用户额外配置。
6. UI 尽量不遮挡图片。
7. 文件操作自然，不迫使用户进入管理模式。
8. 软件长期保持本地、干净、无账号依赖。

## 非目标

不以替代 Photoshop、Lightroom、ACDSee、XnView MP 或 DAM 为目标。
