# Competitive Research Summary

主要参考 BandiView、ImageGlass、JPEGView、qView、Pineapple Pictures、FastStone、IrfanView、nomacs、XnView MP、NeeView、Lumia。

吸收：BandiView 的格式/色彩/文件操作，ImageGlass 的现代 Viewer/缓存/扩展，JPEGView 的 Minimal GUI，qView/Pineapple 的轻量，同屏控件按需出现，nomacs 的 Compare 思路，Lumia 的 Heavy Codec 隔离和 Huge Image Tile 思路。

不吸收：图片管理、批处理、复杂编辑、图库数据库等会让 Viewer 膨胀为图片工具箱的方向。
